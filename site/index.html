ராஜராஜ (Rajaraja, a web crawler in Go)

Survey a whole website from one command. Every page fetched once, every link recorded, all in one JSON report.

Read the README View the code on GitHub
$ go install github.com/its-me-sv/rajaraja-web-crawler@latest

45 pages, 394 links read and 2.4 seconds with five workers. Not one page fetched twice. One third-party library.

Ask the report anything

Rajaraja hands you raw material, not a verdict. One JSON file, five fields per page, ready for jq, a spreadsheet or a graph tool. These answers are computed live from the crawl above.

What one worker does

        
Every link gets its own goroutine. Each one runs these steps, and dozens run at once. The hard part is steps 1 and 4: sharing one map between racing workers without fetching a page twice or passing the page limit.

      

      

        
    
          
  1. Wait for a free slot
    A buffered channel works as a semaphore, so only maxConcurrency workers fetch at a time.
    chan struct{}
    2. 
          
  2. Stay on the site
    Links to another hostname are listed in the report but never fetched.
    3. 
          
  3. Turn the URL into a page key
    Scheme, fragment, default port and trailing slash go, so http://Example.com/a/ and https://example.com/a#top are one page.
    4. 
          
  4. Claim the page and check the limit
    Both happen inside one locked section, so two workers can never take the same page or overshoot maxPages.
    sync.Mutex
    5. 
          
  5. Fetch it
    One shared HTTP client with pooled connections, a 7 second timeout and the user agent RajarajaWebCrawler/1.0. Only HTML pages pass.
    6. 
          
  6. Read the page
    Main heading, first paragraph, every link and every image, parsed with goquery.
    7. 
          
  7. Start a worker for every link, then free the slot
    The crawl ends when the last worker finishes, with no queue to close.
    sync.WaitGroup
    8.

Named after an emperor who surveyed his empire

        
ராஜராஜ சோழன் is written Rajaraja Chozhan and said RAH-jah-RAH-jah CHOH-zhun. Rajaraja Chola I ruled from 985 to 1014 and built the great temple at Thanjavur. Around the year 1000 he began a survey and assessment of the land across his empire, and the land was reorganised into new revenue divisions. An officer called Kuravan Ulagalandan led the work, and the results were cut into the stone walls of temples. Later rulers updated the survey from time to time.

What it does not do yet

        
Rajaraja maps what a site links to. It does not judge it, and it says so.

      

      
    
        
  • No JavaScript rendering. Single-page apps without server rendering show up as one page with no links.
    • 
        
  • No robots.txt or crawl delay. Crawl sites you own or are allowed to, and start with one or two workers.
    • 
        
  • Broken links and redirects are not reported. Failed pages are left out, and redirects are followed silently.
    • 
        
  • No depth limit. The page cap is the only bound, and capped crawls can pick different pages each run.
    • 
        
  • Some markup is ignored: title, meta description, canonical, meta robots, nofollow and the base tag.
    • 
      

    


    

      
Map your own site

      
Build it from source in under a minute. Flags, the report format, design choices and the full list of rules are in the README.

      

        $ git clone https://github.com/its-me-sv/rajaraja-web-crawler.git
$ cd rajaraja-web-crawler
$ go build -o rajaraja-web-crawler .
$ ./rajaraja-web-crawler https://example.com 2 100
